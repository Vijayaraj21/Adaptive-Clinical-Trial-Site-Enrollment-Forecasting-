MODEL

Bayesian enrollment forecasting

The forecasting service uses a hierarchical Negative Binomial model to represent variation between recruiting sites and uncertainty in weekly enrollment. Hospital patient-flow covariates provide changing context for each site's recruitment capacity.

Posterior simulation produces completion distributions, credible intervals, deadline probabilities, and site-level risk estimates. Scenario analysis evaluates operational changes without rewriting observed trial history.

DATA LIFECYCLE

One service, shared records

Trial metadata and the site-week enrollment panel are loaded by the FastAPI service. With MySQL enabled, panel updates, account records, and password hashes persist in the configured database. The dashboard, account forms, and API documentation use this same backend.
